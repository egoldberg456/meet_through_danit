# Meet Through Danit

Website for Meet Through Danit, a Jewish matchmaking and dating-coaching practice. It is a static HTML/CSS site with no build step.

## Pages

- `index.html` - Home
- `about.html` - About Danit
- `services.html` - Services and booking links
- `testimonials.html` - Testimonials
- `faq.html` - FAQ
- `join.html` - Join the free database
- `ask.html` - Get in touch
- `privacy.html` - Privacy Policy
- `terms.html` - Terms and Conditions
- `404.html` - Page not found (served by the host for unknown URLs)

## Other files

- `robots.txt` - Crawler rules and sitemap location
- `sitemap.xml` - Public pages for search engines (excludes `join.html` and `ask.html`)
- `og-image.jpg` - 1200x630 image used for link previews

Canonical and link-preview URLs assume the domain `https://meetthroughdanit.com`.
## Preview locally

From the repo root:

```
python3 -m http.server
```

Then open http://localhost:8000.

## Site copy

The site copy lives in these HTML files and is the latest copy.
